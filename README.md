# Friend Feed downloads

Installers for the Friend Feed desktop app, the companion to the free Friend Feed addon for World of Warcraft: Forever.

- Windows: https://github.com/kingswoop/friendfeed-releases/releases/latest/download/FriendFeed-Setup.exe
- macOS: https://github.com/kingswoop/friendfeed-releases/releases/latest/download/FriendFeed.dmg

The app updates itself from the releases published here.

Website, help and the addon: https://friendfeedwow.com
